CANIVETE SUIÇO TECNICO - CHECKLIST DE FERRAMENTAS
=================================================

Este arquivo lista todas as ferramentas que você deve colocar no pendrive.

É IMPORTANTE: Você precisa BAIXAR as ISOs de cada ferramenta e colocar nas pastas.
Nada vem pré-instalado no pendrive. Você que adiciona conforme precisa.


FERRAMENTAS RECOMENDADAS
=======================

 COMO USAR
=========

1. Instale o Ventoy no pendrive
2. Crie as pastas (execute manager.bat opção 1)
3. Baixe as ISOs das ferramentas acima
4. Coloque cada ISO na pasta correta
5. Reinicie o PC
6. Dé boot pelo pendrive
7. Escolha a ferramenta no menu


TAMANHO DO PENDRIVE
==================

Recomendação:
- Mínimo: 16 GB
- Ideal: 32 GB ou mais
- Razão: As ISOs ocupam bastante espaço


PROXIMOS PASSOS
===============

1. Execute manager.bat
2. Escolha opção 1 para criar a estrutura
3. Baixe as ISOs
4. Copie para as pastas
5. Teste o pendrive
